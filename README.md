# 世界檔案庫｜World Archive

這是個人世界觀資料庫，使用繁體中文。

## 網站
GitHub Pages 啟用後可由以下網址瀏覽：
https://3rtyuikl.github.io/world-archive/

## 更新資料
- 網站入口：`index.html`
- 世界觀與角色資料：`data/world.json`
- 新增或修正角色時，優先編輯 JSON，不需要修改網站版面。
- 每次 GitHub commit 都會保留版本紀錄。

## GitHub Pages
Repository → Settings → Pages → Build and deployment：
選擇「Deploy from a branch」，Branch 選 `main`，資料夾選 `/ (root)`，按 Save。
